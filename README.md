# Weather Forecast

A small weather dashboard built using React and Tailwind CSS.
It fetches real-time weather data and air quality information using the OpenWeather API.

## Features

Search any city with autocomplete

Current temperature and weather condition

Wind speed, humidity, visibility

Air Quality Index 

Clean dark dashboard layout

## Tech Stack

React (Hooks)

Tailwind CSS and 

Vite and

Axios and 

OpenWeather API
